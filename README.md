# Python Data Structures & Control Flow Examples

This repository contains a Jupyter Notebook (`.ipynb`) file demonstrating fundamental Python concepts related to data structures (lists, dictionaries, sets) and basic control flow (conditional statements).

## Table of Contents

*   [Lists](#lists)
*   [Dictionaries](#dictionaries)
*   [Sets](#sets)
*   [Conditional Statements](#conditional-statements)

## Lists

-   **Initialization:** Creating a list of integers.
-   **Type Checking:** Verifying the data type of the list.
-   **Element Insertion:** Adding an element at a specific index (`insert()`).
-   **Element Removal:** Removing the last element (`pop()`).
-   **List Extension:** Adding multiple elements from another iterable (`extend()`).
-   **Sorting:** Sorting the list in descending order (`sort(reverse=True)`).
-   **Aggregate Functions:** Calculating `max()`, `min()`, and `sum()` of list elements.
-   **Accessing Elements:** Printing the first, last, and a slice of elements.
-   **Reversing:** Printing the list in reverse order using slicing.

## Dictionaries

-   **Initialization:** Creating a dictionary with string keys and integer values.
-   **Type Checking:** Verifying the data type of the dictionary.
-   **Accessing Values:** Retrieving a value using its key.
-   **Adding New Key-Value Pairs:** Dynamically adding a new entry.
-   **Updating Values:** Modifying the value associated with an existing key.
-   **Viewing Keys, Values, and Items:** Using `.keys()`, `.values()`, and `.items()` methods.

## Sets

-   **Initialization:** Creating a set of characters, demonstrating automatic removal of duplicates.
-   **Type Checking:** Verifying the data type of the set.
-   **Understanding Unordered Nature:** Notes on why direct indexing (e.g., '4th position') is not applicable to sets.
-   **Set Operations:** Performing `union()` and `intersection()` between two sets.

## Conditional Statements

-   **User Input:** Taking integer input from the user.
-   **`if-elif-else` Structure:** Implementing a conditional logic to categorize a score (e.g., 'above average', 'average', 'below average') based on predefined thresholds.
